Classic Caesar
Chopped Romaine · Parmigiano Reggiano · House-Made Dressing
The Story

Romaine gets chopped, not torn, then tossed in a house-made Caesar dressing built fresh in the kitchen, no shortcuts, no bottle. Croutons are baked in-house too, never bagged.

Three ingredients, done right, beats ten done average. Every plate gets the same finish, every time, so it tastes the same on a Tuesday as it does on a Saturday.

The Finish
Parmigiano Reggiano gets grated fresh over the top right before the plate goes out, so it falls like a light snow over the romaine. Never pre-grated. Never sitting in a container.
